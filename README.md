# 웹 슬라이드 메이커

PPT 대신 쓰는 한 파일짜리 발표 자료 도구입니다. 링크로 열면 항상 최신 버전이 열립니다.

## 쓰는 법
1. 링크를 열고 오른쪽 위 **[편집]** · **[설정]**으로 자료를 만듭니다.
2. **[완성본 저장]**: 내 컴퓨터로 완성 자료(HTML)를 내려받습니다. 발표자 모드 · PDF만 남은 깨끗한 파일입니다.
3. 나중에 이어서 고치려면 [설정] → **작업본 저장**, 다시 열 때는 링크에서 [설정] → **작업본 불러오기**.

## 개인정보 · 보안
- 이 페이지는 파일을 보여주기만 합니다. 편집한 내용은 **내 브라우저 안에만** 있고, 저장하면 **내 컴퓨터로만** 내려받아집니다.
- 도구는 인터넷으로 아무것도 보내지 않습니다. 이 저장소에는 도구 파일(`index.html`)만 있습니다.
- 각자 만든 자료 파일은 이 저장소에 올리지 마세요.
